New backup

A backup is one JSON file of groups, zones, environments, workers, users (no password hashes) and config, tagged with the release version. Secrets are not included. Target is where it is written: local keeps it on the console's disk, bucket uploads it to the groups bucket; the optional path overrides the default name.

Preview a restore before running it. A restore merges the backup over the current state and never deletes on its own; restore and prune also removes what the backup does not contain. Both end every other signed-in session.
