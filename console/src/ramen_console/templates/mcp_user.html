How to connect

Ask an admin for the console's OAuth client id for your client (Config → OAuth clients), then point the client at a zone of one of your groups:

claude mcp add-json ramen-{{ groups[0] }} '{"type":"http","url":"{{ public_url }}/mcp",
  "headers":{"ramen-group":"{{ groups[0] }}","ramen-zone":"<zone>"},
  "oauth":{"clientId":"<client id>","scopes":"mcp:{{ groups[0] }}:<zone>"}}'

Then run /mcp in Claude Code (or open the server in your client) and approve it in the browser window it opens. The zone names come from the admin who deployed the group.
