Workers per group

One row per group × zone. A worker is one pod: the Rust node (gRPC + Streamable HTTP, auth, limits) plus a Python sidecar that runs the group's tools. The sidecar starts on the first call and is stopped after RAMEN_SIDECAR_IDLE_SECS (default 300) without calls, then starts again on the next one — "sidecar stopped" in a log is idle, not broken; set a very large value on the deploy to keep it warm. The live cell refreshes every 15 s: one entry per worker with its load (low / even / high, calls in flight over total) and the canary when one is running.
