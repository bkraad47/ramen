# llms.txt

This site publishes an [`llms.txt`](llms.txt) (the [llmstxt.org](https://llmstxt.org) convention) so that LLM agents and
crawlers can find the right page without scraping the whole site. It lists every page with a one-line summary.

```
https://bkraad47.github.io/ramen/llms.txt
```

The landing page also carries a `schema.org/SoftwareApplication` JSON-LD block (name, version, license, repository,
keywords) for search engines and agent portals.
